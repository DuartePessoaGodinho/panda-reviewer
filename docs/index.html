Core capabilities

A compact review desk for repeated MR work.

Panda Reviewer focuses on the actions reviewers repeat every day: find what needs attention, inspect enough context, open the right local repo, and finish the review.

MR queue, not a browser tab

Separate "To Review" and "My MRs" views make incoming requests and your own open work visible.

CI, comments, approvals

Cards expose draft, approval, pipeline, comment, branch, project, and freshness signals before you open a diff.

Open the local repo

Configure repo folders once, then jump into VS Code, IntelliJ, or your preferred IDE from the MR.

Workflow

The tray watches quietly until review work needs attention.

The app mirrors the real review loop: polling, queue triage, local repo detection, optional AI review, and quick approval.

Local AI review is a second pass.

Run a CLI review with Codex, Claude, Copilot, or another configured provider. Output is saved locally per MR so follow-up reviews keep context.

FAQ

Common setup questions.

Does it support self-managed GitLab?

Yes. Use your internal GitLab base URL in Settings and a token with API access for the projects you review.

Is there a hosted Panda Reviewer account?

No. The app talks directly to GitLab from your machine and stores settings locally.

Which AI provider does it require?

The review action is local-provider oriented. Configure the CLI/provider you already use, then run reviews against local branches.

Where do releases live?

Windows installer and portable builds are published on the project's GitHub Releases page.
